# Game Jolt API Docs

Unofficial reference to API calls used by Game Jolt's website, based on its public frontend and observed responses.

The OpenAPI spec includes 159 operations across 158 paths. Source-only details and unresolved runtime URL expressions are labeled in the spec.

Routes and response shapes may change. Scalar's "Try it" button is enabled for the public listing request; browser CORS rules may still block requests.
